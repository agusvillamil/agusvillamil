# Hi, I'm Agustín Villamil

I'm a junior full-stack developer from Bahía Blanca, Argentina. I'm studying Information Systems Engineering at Universidad Nacional del Sur, where I'm also a teaching assistant for Introduction to Object-Oriented Programming, a course taught in Java. Most of what I build uses TypeScript, React, Next.js, Node.js and Python, and lately I've been working on apps that use RAG and language models. I also work as an English-Spanish medical interpreter.

You can see all my work at **[agusvilla.dev.ar](https://agusvilla.dev.ar)**.

## Projects

- **[HAL 2026](https://github.com/agusvillamil/hal2026):** a RAG assistant that answers questions and solves exercises for a Physics I course using its bibliography. Built with FastAPI, ChromaDB, Sentence Transformers and Next.js. You can try it at [hal2026.dev.ar](https://hal2026.dev.ar).
- **[Speech translation assistant](https://github.com/agusvillamil/Transcripcion):** a desktop app that transcribes English and Spanish speech with whisper.cpp and translates it with a local language model through Ollama, all offline on an 8 GB AMD GPU. I compared five translation models on public interpreter practice material.
- **[Palma Turismo](https://palma-turismo.palmaturismo.workers.dev):** a booking platform for a travel agency, built with a university team for a real client over four months. I worked on bookings, payments with Mercado Pago, passenger management and the admin panel, using React, Node.js, Express and PostgreSQL.
- **[Aura Skin](https://auraskinbb.com.ar):** an online store that takes real payments, running on Cloudflare Workers with Supabase and Mercado Pago, with tests in Vitest, pgTAP and Playwright.
- **[Candy Crush in Java](https://agusvilla.dev.ar/candy-crush/):** a match-three game we made as a team for a university course, using Swing, threads and the Strategy and State patterns.
- **[Run Godin Run!](https://agusvilla.dev.ar/run-godin-run/):** an endless runner made in Unity for a local game jam. I wrote the game's code during the jam.
- **[Bubble Defense](https://agusvilla.dev.ar/bubble-defense/):** a Unity game made by a team of seven for the Global Game Jam 2025. I built the main menu, the shop and the timer.
